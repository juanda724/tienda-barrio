Sensibilidad de las pruebas de caracterización (mutaciones temporales)
Fecha: 2026-10-27
Comando: backend\mvnw.cmd test -Dtest=DocumentosPagoCaracterizacionTest

Objetivo: demostrar que las pruebas de caracterización detectan cambios de comportamiento, es decir, que
"todas en verde" después de refactorizar significa que el comportamiento se conservó y no que las pruebas
no miran nada. Cada mutación se aplicó sobre el código ya refactorizado, se ejecutó la prueba y se revirtió.
